# The Best Neighborhood In Pittsburgh

**Team Name:** Best Burgh

**Team Members:** Benson Liu (BEL201@pitt.edu), Yixin Li (YIL644@pitt.edu), Gunjan Baskota (GUB39@pitt.edu)

**Overview:** Our repository consists of three sub-metric (popularity, safety, and value) along with its associated dataset, which are used to define our version of "bestness" when determining the best neighborhood in Pittsburgh.

**Datasets Used In Our Analysis:**

Benson's Popularity Sub-Metric: Pittsburgh SNAP Census Data - Housing 2010 (WPRDC)

Dataset Link: https://data.wprdc.org/dataset/pgh/resource/94f8eda2-fa77-49a2-9190-3a6ed85fc561

Description: This sub-metric uses the popularity count of Pittsburgh neighborhoods in 2010, which is particularly helpful in understanding which neighborhood is the most active and popular one.

---

Gunjan's Safety Sub-Metric: Pittsburgh SNAP Census Data - Public Safety 2010 (WPRDC)

Dataset Link: https://data.wprdc.org/dataset/pgh/resource/bd152875-a14d-421a-8656-cc896a7e9074

Description: This sub-metric uses the Part 1 Crime per 100 Persons on Pittsburgh neighborhoods in 2010, which is helpful in determining which neighborhood is safe when considering the amount of different types of crimes that have been reported.

---

Yixin's Value Sub-Metric: Pittsburgh American Community Survey 2015 - Miscellaneous Data - Housing Unit Value

Dataset Link: https://data.wprdc.org/dataset/5b18c198-474c-4723-b735-cc5220ad43cc/resource/13982f58-e618-400c-8f69-6a32dbd7c68f/

Description: This sub-metric uses the number of high-value homes in Pittsburgh neighborhoods to determine which neighborhood is the best, which can be defined as the one that has the most number of expensive homes and access to premium amenities.
